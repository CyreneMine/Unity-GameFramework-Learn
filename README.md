## 打开工程

1. 在 Unity Hub 中添加本仓库根目录，使用 `6000.3.10f1` 打开。
2. 如需查看初始场景，打开 `Assets/Scenes/SampleScene.unity`。当前 Build Settings 场景列表为空，不声称已配置构建。
3. 学习参考资料不随仓库分发，可按教程目录中的课时编号查阅。

`Packages/manifest.json` 包含 Input System `1.18.0` 和 UGUI `2.0.0`；当前启用新 Input System。教程 P50–P53 的配套源码使用旧输入 API；当前仅略学 P50 的思路，暂跳 P51–P53，不要求切换工程输入设置。

## 学习与提交约定

按教程目录已记录的学习深度推进；用户调整范围时再同步文档。精学重在理解与自己实现，略学看清思路，暂跳项以后按需回看。观看、跟做、独立实现和运行验证分别记录。后续提交与 push 均在用户明确要求时执行。

仓库保留 Unity 工程所需的 `Assets`（含 `.meta`）、`Packages` 和 `ProjectSettings`；Unity 缓存、IDE 自动文件、个人设置和构建输出由 `.gitignore` 排除。
