## 打开与使用

1. 在 Unity Hub 添加仓库根目录，使用 `6000.3.10f1` 打开。
2. 打开 `Assets/Scenes/P11PoolTest.unity`，点击 Play。
3. 将鼠标移到 Game 窗口，左键生成 Cube，右键生成 Sphere。
4. 对象出现在随机位置，约 2 秒后失活并回到对象池。再次点击时复用同类对象。

对象通过资源键 `P11/PoolCube`、`P11/PoolSphere` 获取。两个预制体已挂载 `PoolObj`，上限分别为 5、3。示例沿用工程的新 Input System，以 `WaitForSeconds(2)` 计时；游戏时间缩放会影响等待时长。场景用于观察当前对象池的普通取还流程。

菜单 `Tools → 学习检查 → P11` 提供资源生成及脚本工程同步入口。资源生成工具只补齐缺少的同名预制体和场景，不覆盖已有文件；编辑器有未保存场景时会先询问保存。

简化脚本在 P13 改造前已通过 Unity 编译及协程检查。在独立工程副本的真实 Play Mode 中，临时验证驱动直接启动其实际 `Spawn` 协程：两种对象在约 1.5 秒时仍激活，超过 2 秒后失活，再次获取复用同一实例且每种数量仍为 1。此检查覆盖当时的创建、计时和回收逻辑；批处理中的鼠标按下边沿未自动验证，实际左右键触发请在 Game 窗口确认。临时驱动没有加入本仓库。

当前 P13 抢占策略不会取消旧使用者的协程。若同类对象在约 2 秒内借出超过上限，旧协程可能归还已被重新借出的对象，并造成后续重复归还；示例用于普通取还观察，不能据此认定抢占与延时回收结合时也安全。最新 48 项检查直接调用对象池接口，没有自动验证鼠标触发或重跑等待 2 秒的协程用例。
